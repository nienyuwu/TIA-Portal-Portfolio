This repository documents my hands-on work in PLC-based automation, focusing on **solving engineering problems through practical control system design, implementation, and validation**.

The portfolio progresses from fundamental PLC control to integrated industrial automation systems.

## Engineering Approach

Each project is designed around an engineering problem rather than a specific PLC feature.

The development process follows:

```text
Engineering Problem
        ↓
Requirements & Constraints
        ↓
System Design
        ↓
Control Strategy
        ↓
PLC Implementation
        ↓
Testing & Validation
        ↓
Results & Improvements
```

PLC technologies such as timers, counters, state machines, FB/FC, analog control, and motion control are introduced when they are appropriate for solving the problem.

The objective is not to demonstrate as many PLC features as possible, but to develop **reliable, maintainable, and practical automation solutions**.

---

## Project Development

Each project includes, where applicable:

* Engineering problem and objectives
* System overview
* I/O mapping
* Control strategy
* PLC program structure
* Factory I/O digital twin
* HMI operation
* Fault and alarm handling
* Normal and abnormal operation testing
* Validation and results
* Lessons learned
* Future improvements

Particular attention is given to **fault detection, recovery, interlocks, and abnormal operating conditions**, reflecting the requirements of real industrial automation systems.
